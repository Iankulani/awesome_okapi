Awesome Okapi_v1 is a cybersecurity penetration-testing and security-awareness platform designed for authorized security professionals, penetration testers, researchers, and cybersecurity students. The platform provides a centralized way to manage approved security-testing activities through Discord, Telegram, Slack, Google Chat, WhatsApp, Signal, and a web application.

Authorized users can submit predefined security-testing commands, monitor assessment tasks, review results, and generate security reports. Awesome Okapi_v1 uses authentication, role-based access control, target-scope validation, command allowlisting, approval workflows, and audit logging to help prevent unauthorized activity.

The platform can support controlled vulnerability assessments, reconnaissance within approved environments, laboratory exercises, security monitoring, and penetration-testing workflows. Testing operations can be executed in isolated laboratory environments or other explicitly authorized infrastructure.

Awesome Okapi_v1 also includes a phishing-awareness simulation capability for authorized security-training campaigns. Simulations can direct participants to organization-controlled educational pages that explain common phishing indicators. The system should not collect real passwords, authentication tokens, or unnecessary sensitive information.

The web dashboard provides project management, target configuration, user management, assessment monitoring, vulnerability tracking, audit logs, and reporting.

Awesome Okapi_v1 — Authorized Testing, Controlled Execution, Secure Security Operations.
